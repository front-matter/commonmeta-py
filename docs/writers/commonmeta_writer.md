This page shows how to generate a metadata in Commonmeta format. Commonmeta is the internal format used by commonmeta-py, all readers generate metadata in this format, and all writers use commonmeta as input.

## Fetch metadata

```python
from commonmeta import Metadata

# Fetch metadata from a DOI
string = "10.1155/2012/291294"
metadata = Metadata(string)

# Check that metadata was fetched and is valid
print(metadata.is_valid)
```

```
True
```

## Generate Commonmeta

We can now generate commonmeta.

```python
commonmeta = metadata.write()
print(commonmeta.decode())
```
